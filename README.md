# Tetris-With-Spring-Boot
Practice Tetris program with Spring Boot features
This tetris program uses Java, SpringBoot, and a few other tools to create a fully playable Tetris game with multiplayer capabilities, leaderboard tracking, and the option for user accounts.

## Goals and Objectives

*   **Goal 1:** To provide a simple, user-friendly Tetris game that is fully playable
*   **Goal 2:** To provide the Tetris game with Leaderboard functionalities
*   **Goal 3:** To implement user account capability in the Tetris game using Spring Security
*   **Goal 4:** To implement multiplayer (competitive) modes using Spring Boot and websockets
*   **Objective:** Help develop and demonstrate knowledge in Java, Spring Boot, and the other tools utilized to further my personal developer experience.

## Key Features

*   Tetriminos: Seven unique geometric shapes (I, O, T, S, Z, J, L) composed of four blocks each.
*   Line Clearing: Filling an entire horizontal row with blocks makes it disappear. Clearing four lines at once with an "I" piece is called a "Tetris".
*   Rotations and Movement: Players can move pieces horizontally and rotate them to fit into spaces.
*   Speed Scaling: Pieces fall faster as more lines are cleared, increasing difficulty as the game progresses.
*   Next Queue: Displays upcoming pieces, allowing players to plan their stacking strategy.
*   Hold Queue: Allows players to reserve a piece for later use.
*   Hard Drop/Soft Drop: Players can instantly lock a piece at the bottom (Hard Drop) or speed up its descent (Soft Drop).
*   Game Over Condition: Occurs when the blocks reach the top of the Matrix ("topping out").
*   Leaderboard: Database stores global leaderboard scores and retrieves the high scores and presents to a display
*   User account: Game allows users to either be 'guest' or signed in to remember their account info for the leaderboard
*   Multiplayer mode: A competitive game mode that allows people to join a match-making queue and compete against other online users
